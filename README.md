# Android Game Hit Prediction & Market Analytics 🎮

A machine-learning research project analyzing 10,150 mobile games to study revenue and predict hit success.

## Technology
- Python
- Pandas and NumPy
- scikit-learn
- Linear and logistic regression
- Seaborn
